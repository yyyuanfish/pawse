Problem
Nobody has checked real microphone capture, audio upload, the desktop-width layout, or speech recognition with real recordings in English, Chinese, German and Hindi. The only audio test used a silent file (see docs/VALIDATION.md, "Not verified or not connected"). The redesigned frontend (#6) and the Gemini Live client (#22) are not built yet, so there is nothing to click through today.

Approach: tests first
Write the browser suite now, against a written frontend contract (data-testid hooks + data-state on the cat), so #6 / #22 are built to pass it. The tests are red until the UI lands, then they turn this manual checklist into a repeatable command.

Mic capture (Chromium fake audio device fed a real WAV): the recording that reaches /voice/transcriptions is a non-silent mono 16-bit WAV of the recorded length that the server accepts; mic tracks are released after stop; permission denied and no-mic show a recovery message and keep the typed flow usable.
Audio upload: stereo / 48 kHz / 8 kHz WAVs are played locally and converted; too short, too long and non-audio files are rejected before any upload; a replacement recording wins.
Desktop layout: 1280, 1440, 1920 and 390 px widths: no horizontal scroll, no overlapping controls, transcript and results side by side on desktop, simulated labels visible.
Gemini Live client (mocked token + mocked Live WebSocket): consent gate, 16 kHz PCM16 mic frames, transcripts rendered as text, tool calls forwarded and answered, confirm_call gate, failure fallbacks.
Real recordings (opt-in, real Gemini key, recordings kept off git): WER/CER per language for en, zh, de, hi, once through the API and once through the browser mic.
Done when

Suite merged and runnable: PAWSE_E2E=1 pytest tests/browser (red until Frontend + design: cat companion UI (states, mic, transcript, results) #6/Frontend: Gemini Live voice client (mic, playback, transcript, tool chips) #22 implement the contract)

Contract in tests/browser/README.md linked from Frontend + design: cat companion UI (states, mic, transcript, results) #6 and Frontend: Gemini Live voice client (mic, playback, transcript, tool chips) #22

Human recordings collected (with consent, stored off git) for en, zh, de, hi

Suite green against the new frontend; docs/VALIDATION.md updated with what was really verified
