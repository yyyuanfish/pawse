Goal
Connect yyyuanfish/pawse to the Entire platform (https://entire.io) so our AI agent sessions (Claude Code, Gemini CLI, Cursor, ...) are captured as checkpoints next to the commits. It is useful context for the jury (#9) and possibly a partner tech.

Current state (Ari's Entire dashboard)
11 repositories onboarded, 0 capturing, checkpoint streak 0, no sessions yet: the CLI is not set up on any machine.
pawse is owned by yyyuanfish, so the Entire GitHub App must be installed on that account (or Ari needs admin on the repo) for it to show up.
Tasks

Entire GitHub App: get yyyuanfish to install/authorize it for pawse (read-only access to code, metadata, PRs; it never writes to the repo). Docs: https://docs.entire.io/guides/repositories/github-app-access

Install the CLI on the dev VM: curl -fsSL https://entire.io/install.sh | sh

Enable it in the repo: entire enable (checkpoints go to the hidden branch entire/checkpoints/v1; optionally use --checkpoint-remote github:<org>/<repo> to keep them out of the public repo).

Decide privacy: the repo will be public for the submission. Check whether session transcripts could leak keys or private prompts before pushing checkpoints.

Verify: run one Claude Code session, commit, push, and confirm the session/checkpoint appears on entire.io for pawse ("Capturing" > 0).

Ask teammates (Shivamm08, sleepynami11, yyyuanfish) to install the CLI too, so all sessions are captured.

Check whether Entire is a listed hackathon partner (Partners tab). If yes, count it towards the 2-partner rule in Submission: ensure full hackathon submission is complete (deadline 19:00) #9 and mention it in the README.
Done when
pawse shows as capturing on Entire with at least one checkpoint linked to a commit, and the README notes how the team uses it.
Docs: https://docs.entire.io/platforms/cli-and-entire-io · https://docs.entire.io/cli/checkpoints
