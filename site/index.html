A FEW THINGS TO KNOW

Care starts
with honesty.

Does Pawse diagnose my cat?

No. Pawse is a hackathon prototype for care navigation. Photo observations are not a diagnosis or validated automated pain assessment. If your cat needs urgent care, contact a veterinarian directly.

Will it call the vet or book an appointment?

The core flow prepares a reviewed script and playable audio, with phone-dialer links where available. Automated calling is limited to configured demo integrations; the rehearsal labels simulated calls. A suggested appointment is not a confirmed booking.

Can I really use my own voice?

The voice setup supports recording, consent, preview and German localization through Gradium when configured. Only use your own voice or one you have permission to use. You review the script before generating audio.

Is my insurance definitely covered?

No. Policy evidence is a starting point, not an insurer's approval. The demo uses a synthetic policyholder scenario. Verify your actual policy and coverage with your insurer.

What should I expect from this prototype?

Some integrations depend on deployment configuration. This site opens the connected Pawse App; live features depend on its backend and provider availability. Photo features require the latest backend release. The clearly labelled rehearsal is available if a live provider is unavailable.
